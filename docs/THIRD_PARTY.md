# Third-party components and licences (`docs/THIRD_PARTY.md`)

Faro is **Apache-2.0** (`LICENSE`). Everything below is compiled into, or linked by, a Faro binary.
Full licence texts are in `LICENSES/`; the short attribution list is `NOTICE`.
`scripts/package_release.sh` puts `LICENSE`, `NOTICE`, `LICENSES/` and this file into every release archive
and into the `.deb` (`/usr/share/doc/faro-desktop/`). `scripts/license_audit.sh` checks that this file, `NOTICE`
and `LICENSES/` are present and that no copyleft code is in our own sources.

Columns: **FW** = firmware images (`faro_tdeck`, `faro_tdeck_max`, `faro_heltec_v3`, `faro_tbeam_supreme`,
`faro_thinknode_m9`), **Host** = `faro-sim` / `faro-console`. Versions are the ones PlatformIO resolves for
the pinned MeshCore submodule; check `external/MeshCore/.pio/libdeps/<env>/` after a build.

### LGPL-2.1 components and your rights

MicroNMEA, Arduino_LPS22HB and the arduino-esp32 core are statically linked into the firmware images.
LGPL-2.1 lets you change these libraries and relink the firmware with your version. Faro meets this by being
fully open source: the whole firmware is built from this repository (Apache-2.0), the pinned MeshCore
submodule (MIT) and the versions listed above. To relink:

```bash
git submodule update --init
scripts/link_env.sh
# edit or replace the library under external/MeshCore/.pio/libdeps/<env>/ (or point lib_deps at your fork)
pio run -d external/MeshCore -e faro_tdeck
```

The source of the LGPL components for a release is available from their upstream repositories at the
versions above. For at least three years after each release we will also provide it on request
(open an issue at https://github.com/radek-sixi/sixi-tdeck-plus/issues).

## Map tiles (`scripts/make_sd_map.py`)

Faro does not ship map tiles. `make_sd_map.py` downloads tiles only from a server you name with `--tiles-url`.
You are responsible for using a provider whose terms allow offline/bulk download, or for rendering your own
tiles. `tile.openstreetmap.org` does **not** allow this (OSMF Tile Usage Policy,
https://operations.osmfoundation.org/policies/tiles/), so the script refuses it.

Tiles made from OpenStreetMap data must show **"© OpenStreetMap contributors"** (data licence ODbL 1.0,
https://www.openstreetmap.org/copyright), plus whatever attribution the tile style or provider requires.
Keep that attribution with the SD card image and show it wherever the map is shown.
