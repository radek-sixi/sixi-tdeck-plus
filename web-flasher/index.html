Faro v0.10.1 — Web Flasher & Downloads

Flash from Chrome or Edge over USB-C (Web Serial), or download the firmware and Ubuntu packages. Faro is an open-source LVGL 9 touch/keyboard UI for upstream MeshCore.

Firmware
